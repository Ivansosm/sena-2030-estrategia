# SENA 2030 · Decidir hoy, sostener el futuro

Presentación interactiva sobre pensamiento estratégico y prospectiva aplicada al SENA.

**Autores:** Iván Leonardo Sosa Munévar y Natalia Andrea López Hernández.

Incluye 14 escenas con navegación espacial, animaciones, escenarios, gráficos interactivos, fichas de indicadores, guion y referencias.

## Uso

Abre `index.html` en un navegador. El contenido y las interacciones funcionan sin conexión; los enlaces bibliográficos requieren internet.

## Publicación

Sitio estático preparado para GitHub Pages, con publicación desde la rama `main`, carpeta raíz.

## Alcance académico

La red territorial adaptativa, la comparación de alternativas, los escenarios y las metas son propuestas académicas. No representan decisiones oficiales ni resultados medidos del SENA.
